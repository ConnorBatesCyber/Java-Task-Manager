# Java Task Manager

A desktop task management application developed using Java and Swing as part of my Computer Information Systems coursework, featuring a custom retro terminal-inspired interface.

## Project Overview

The Java Task Manager is a desktop application designed to help users create, organize, and track tasks through a graphical user interface.

The application supports task creation, editing, deletion, priority management, due date tracking, and task completion. It also includes search, filtering, sorting, and local file storage capabilities.

This project demonstrates my understanding of object-oriented programming, graphical user interface development, event-driven programming, and file management using Java.

## Features

- **Task Management:** Add, edit, delete, and mark tasks as completed.
- **Priority Levels:** Assign high, medium, or low priorities.
- **Due Date Tracking:** Set deadlines and identify overdue tasks.
- **Task Sorting:** Sort tasks by priority or due date.
- **Search Functionality:** Search for tasks by name.
- **Task Filtering:** Display all, active, or completed tasks.
- **Overdue Highlighting:** Visually identify overdue tasks.
- **Data Persistence:** Save and load task information using local text files.
- **Input Validation:** Validate task names and due date formatting.
- **Custom Interface:** Retro terminal-inspired design featuring neon colors and a dark background.

## How to Run the Application

### Requirements

- Java Development Kit (JDK)
- Eclipse IDE (optional)

### Instructions

1. Download or clone this repository.
2. Open the project directory in a terminal or command prompt.
3. Compile the Java source files:

```bash
javac Task.java TaskManagerApp.java
```

4. Run the application:

```bash
java TaskManagerApp
```

Alternatively, import the source files into an Eclipse Java project and run `TaskManagerApp.java`.
